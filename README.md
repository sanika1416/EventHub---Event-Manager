## Getting Started

### Prerequisites

Install the tools required by your project, such as Node.js, npm, and MongoDB if applicable.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sanika1416/EventHub---Event-Manager.git
   ```

2. Open the project directory:

   ```bash
   cd EventHub---Event-Manager
   ```

3. Install dependencies in the relevant frontend and backend directories.

   ```bash
   npm install
   ```

4. Configure environment variables using a local `.env` file. Refer to `.env.example` if provided.

5. Start the application using the scripts defined in your `package.json`.
